# Melina Chhetri — Portfolio

A single-page, mobile-first portfolio site. No build tools needed — just open `index.html`.

## Files
- `index.html` — all sections (Hero, About, Experience, Skills, Work, Education, Languages, Contact)
- `styles.css` — colors, dark/light theme, responsive layout
- `script.js` — editable portfolio items at the top, theme toggle, filters, animations

## How to customize
1. Add your photo as `assets/images/profile.jpg`
2. Add 4–6 of your best posts/reels/posters to `assets/images/`
3. Update the `PROJECTS` array at the top of `script.js` with your image paths + captions
4. Put your CV at `assets/cv.pdf`
5. Update social links in the Contact section of `index.html`

## Free hosting (pick one)
**GitHub Pages:** push this folder to a GitHub repo → Settings → Pages → deploy from main branch → site goes live at `https://<username>.github.io/<repo>/`.

**Netlify:** drag-and-drop this folder onto https://app.netlify.com/drop → instant live URL.

**Vercel:** install the Vercel CLI, run `vercel` inside this folder, or import the GitHub repo at https://vercel.com.
